**Collaborator illustration (3194), in detail.** Roles are communicated by activity and objects: the coordinator stands at a desk of screens with a headset (directing), the search agent is a globe under a magnifier with documents (finding), the analysis agent is a parchment, chart and robotic arm (extracting), the synthesis agent is a quill, parchment and hourglass (writing). Each card also lists its tools. Task and result arrows run both ways. What it does not show: what the coordinator withholds, who is allowed to do what, or that a separate context is not a security boundary. The atlas keeps the "recognisable by activity" mechanism and adds the bounded work order, the configured permission and the returned evidence.
