Three questions I ask.

  1. Who controls the next step?

    Choose Harness. The model proposes; the application coordinates tools and enforces execution limits.

  2. Where does the evidence enter?

    Choose RAG. Retrieval brings relevant evidence into the model's context. The generated answer still needs to be checked against its sources.

  3. How do the systems connect?

    Choose MCP, then A2A. MCP can expose tools and other capabilities. A2A can exchange tasks between agent services. Each is a separate architecture choice.
