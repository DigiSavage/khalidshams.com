The largest model does not need to attend every meeting.

For a bounded task, I would compare a deterministic rule, a smaller model and a larger model against the same acceptance cases.

Include awkward inputs, missing evidence and cases that should escalate. Decide the escalation rule before comparing the cost. A cheap first attempt can become an expensive workflow if every result needs repair.

Record cost per accepted task, elapsed time and human corrections. Include failed attempts in the bill, and keep test measurements separate from a production forecast.

Then route only the work whose behavior has been demonstrated.

The reusable artifact is the task boundary and evaluation set. The model name is one replaceable choice inside it.
